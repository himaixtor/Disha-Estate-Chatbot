This is any ordinary client website

It has no React, no build step, and no knowledge of the chatbot's internals — it only includes the single script tag this page adds below. The chat bubble in the bottom-right corner is the entire embed.

This page talks to whichever backend is serving it: on your own machine during local development that's http://localhost:5002 (run npm run dev inside backend/ first); once this file is deployed, it automatically talks to that same server instead — see host.md.
